# Expanded materials

The expanded pack contains 500 repeating 384 × 384 materials. Each `<id>.jpg` is the color tile and each `<id>_height.png` is its matching 16-bit grayscale bump map. Lighter pixels represent raised detail. The UVs and repeat period are shared by both files.

Built-in ImageGen created each color source individually. The processed tiles use overlapping edge strips for continuous wrapping. The height maps estimate relief from local contrast after removing broad tonal variation. The [catalog](materials.json) records the ImageGen prompt for each material.

Select **Графика → Пакет текстури → Проширени со релјеф** to use this pack in Skopje 242. The default **Стандардни** uses the original game materials and **Градски** uses the 64-texture city pack.
