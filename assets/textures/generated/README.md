# Generated city textures

This pack contains 64 individual 480 × 480 RGB PNG albedo tiles for eight outdoor material families. Use repeat wrapping when importing them individually. In Skopje 242, select **Графика → Пакет текстури → Градски**.

## ImageGen prompts

Each tile was generated individually with built-in ImageGen. The shared prompt appears below.

> Photorealistic-natural game surface material. A single square repeating seamless albedo texture of [material]. Realistic municipal surfaces from Skopje, Macedonia. Perfectly orthographic face-on, flat uniformly diffuse illumination, no directional lighting or shadows, no perspective. Show only the material, extending edge to edge, with consistent density and scale. Approximately [three or four] meters across. If the material is laid in rows, align edge joints and repeat whole courses. No horizon, objects, border, captions, logos or text.

Asphalt, paving, vegetation and earth use three meters. Plaster, masonry, roof and metal use four meters. The first asphalt tile used its own prompt.

> Photorealistic-natural game material source asset. Generate exactly one square seamless repeat albedo texture of weathered dark charcoal fine aggregate roadway asphalt from Skopje, perfectly orthographic top down, uniform diffuse neutral illumination, realistic tiny mineral chips, restrained tonal variation, approximately 3 meters across, no road markings, no large cracks, no objects, no shadows, no borders, no text. Material covers the entire square and continues across opposite edges.
