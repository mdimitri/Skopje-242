# Prompts for likovi2 characters (ChatGPT image generation)

Goal: match the existing `likovi.png` sheet. Each character is a hand-painted caricature with a big head, small body and exaggerated nose, ears and lips. Use a warm, slightly gritty palette and fine ink lines, on a plain beige paper background. Each one should have one prop that tells a joke about the traits.

## Tips
- **Start a session with the style block:** paste the style block once at the start, then send one character per message ("same style, next: ...").
- **Attach the old sheet:** add `likovi.png` (or one crop from it) as a style reference and say "match this style exactly".
- **Show the traits:** turn each trait into something you can see. "Saves on filling" becomes a burek with almost no cheese, and "doesn't pay for the bus" becomes him jumping the back door of a JSP bus.
- **Pick the pose:** ask for a full-body or waist-up single portrait, 3:4 portrait, with no text and no frame.
- **One character per image:** sheets come out inconsistent. Assemble the sheet yourself.
- **If it goes too realistic:** add "more caricature, bigger head, thicker outlines".
- **If it goes too cartoony or flat:** add "detailed painted shading, visible brush texture".
- **Keep it legal:** don't name real people or real brand logos. Write "fake designer bag", not a brand.
- **Fixes:** reroll a bad result with "keep everything, only change X".
